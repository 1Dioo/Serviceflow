# Service Flow

Sistema desktop para gerenciamento de serviços e agendamentos.

## Tecnologias

- Java 17
- JavaFX
- Maven
- FXML
- CSS
- Git

## Funcionalidades

- Dashboard
- Agenda de serviços
- Cadastro de clientes
- Cadastro de serviços
- Relatórios
- Configurações
- Controle de agendamento
